# Morse Code Trainer

## ▶ [Open the app: rolive11.github.io/morse-code-trainer](https://rolive11.github.io/morse-code-trainer/)

No account or download needed — just click the link above and type your name.

Browser-based Morse code practice for the family. Each page is a single self-contained HTML file —
no install, no internet needed. Open it in Chrome and go.

## Pages

| File | What it is |
|---|---|
| `morse_family.html` | **Main app.** Multiple people (names, no passwords), each with their own settings. Listen, Send, Learn, Check My Skill, My Settings. Large text, light background. |
| `morse_simple.html` | Earlier single-user simple page (Listen / Send / Learn tabs). Kept for reference. |
| `morse_trainer.html` | First, more advanced version (dark theme, Koch method, advanced receive). Kept for possible future use. |

## morse_family.html at a glance

- **Who is practicing?** — pick or add a person. Settings are saved per person in the browser on that computer.
- **🎧 Listen** — letters, words, call signs or sentences; optional CQ, countdown, "keep going until Stop".
- **🔑 Send** — *Send Freely* (key pad + live decoding) or *Copy This Text* (send given text, get a per-letter report).
- **📖 Learn** — 16 Koch-style lessons; letter cards; Hear & Pick, See & Send, Hear & Type, Practice Words.
- **📏 Check My Skill** — one-time listening speed ladder and a PARIS sending check (nothing is stored).
- **⚙️ My Settings** — listening speed/spacing/tone/volume, *Set Up My Key* (measures the person's own dot, dash and pause timing), screen text size.

The key pad works with a mouse click, a trackpad press (press firmly — not tap-to-click), or the Spacebar.

## Notes

- Data lives in the browser's local storage, per computer and per browser. Clearing browser data removes it.
- To set up another computer, copy this folder and add people there.
